# 21.08 Starlette and Uvicorn Refresh

## 2026-11-20

Ran `uv lock --upgrade-package starlette --upgrade-package uvicorn`.
Starlette moves from 1.3.1 to 1.10.0; Uvicorn moves from 0.52.1 to 0.54.0.
No other package record changes. Uv updates the lock format revision from 3 to 5.
Project bounds, application code and tests stay unchanged.

From `grimoire-mcp/`, `uv run --frozen --with pytest python -W default
-m pytest tests ../tests -q` reported
`62 passed, 1 warning, 50 subtests passed in 5.30s` on Python 3.15.2.
The standalone shared-runtime E2E failed its no-child-process assertion.
A diagnostic run identified the child as multiprocessing.resource_tracker.
The same E2E assertion also fails on unchanged origin/main with Python 3.15.2.
The dependency refresh is not required to produce this failure. The import or
operation that starts the tracker was not isolated.

Using the earlier validation runtime, `uv run --python 3.12 --frozen
--with pytest python -W default -m pytest tests ../tests -q` reported
`62 passed, 1 warning, 50 subtests passed in 6.96s` on Python 3.12.
Both unit-suite warnings come from AnyIO's pytest plugin.
Then `.venv/bin/python tests/e2e_shared_runtime.py --output EVIDENCE.json`
reported `shared-runtime E2E passed` and `steps passed: 10`.
This covers authentication, Host/Origin rejection, indexing, queries, 12
concurrent clients on one PID, occupied-port rejection, token permissions
and persisted-index reload. Evidence is retained outside the checkout at
`/home/ubuntu/grimoire-deps-evidence/E-shared-runtime-python312.json`.

The [Starlette release notes](https://github.com/Kludex/starlette/blob/main/docs/release-notes.md)
raise the Python floor to 3.11 and require AnyIO 4, change streamed TestClient
responses, and make repeated-key value order significant in QueryParams
equality. Existing Python and AnyIO requirements remain compatible.
The [Uvicorn release notes](https://github.com/Kludex/uvicorn/blob/main/docs/release-notes.md)
add opt-in experimental HTTP/2 through zttp. This change does not enable it.

Rollback: revert this branch's commit, then run `uv sync --frozen` in
`grimoire-mcp/`. No deployment or shared-service restart is included.
