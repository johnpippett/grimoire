# 21.06 Pillow and Setuptools Security Refresh

## 2026-11-20

Ran `uv lock --upgrade-package pillow --upgrade-package setuptools`.
Pillow moves from 12.3.0 to 13.0.0; setuptools moves from 83.0.0 to 84.2.1.
No other package record changes. Uv updates the lock format revision from 3 to 5.
Project dependency bounds and source code stay unchanged.

The frozen export checked with `uvx pip-audit --disable-pip --no-deps
-r /dev/stdin --format json` reports no advisories for these two packages.
Other packages still have 109 reported findings.
From `grimoire-mcp/`, `uv run --frozen --with pytest python -W default
-m pytest tests ../tests -q` reported
`62 passed, 1 warning, 50 subtests passed in 6.05s` on Python 3.15.2.
The warning comes from AnyIO's pytest plugin.

The [Pillow 13 release notes](https://github.com/python-pillow/Pillow/releases/tag/13.0.0)
drop Python 3.10 and remove deprecated APIs, including ExifTags.IFD.Makernote
and GifImagePlugin._save_netpbm. The project already requires Python >=3.11.
The [setuptools changelog](https://github.com/pypa/setuptools/blob/main/NEWS.rst)
describes compiler changes in 84.0.0. Version 84.1.0 raises UnsafeMember for
unsafe archive members instead of silently skipping them. Version 84.2.1
fixes stable-ABI wheel handling. Grimoire builds with Hatchling.

Rollback: revert this branch's commit, then run `uv sync --frozen` in
`grimoire-mcp/`. This restores vulnerable dependencies. No deployment is included.
