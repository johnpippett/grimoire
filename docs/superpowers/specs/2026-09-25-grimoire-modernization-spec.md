# Grimoire modernization specification

Status: Approved and implemented in the isolated Codex worktree on 2026-09-25.
The installed service and saved checkout still use their prior source. See
[`21.03 Grimoire Modernization`](../../../wiki/20-29%20Implementation%20%26%20Operations/21%20Implementation%20Notes/21.03%20Grimoire%20Modernization.md)
for the implementation and verification record.

**Scope.** Grimoire will keep its Markdown wikis, decimal numbering, local BM25 indexes, shared local MCP runtime, and current refresh schedule. The project instruction file will continue to make wiki reading and writing mandatory across supported harnesses. The implementation will shorten `AGENTS.md` and put installation and numbering instructions in existing setup documentation and `wiki/README.md`. It will update both Grimoire skills, the wiki template, and harness instructions to use the same contract. The wiki will work through ordinary file tools when Model Context Protocol (MCP) search is unavailable. No model memory, embeddings, additional service, or directory migration is necessary.

**Project orientation.** `wiki/README.md` will start with a short project summary, terminology, active work, constraints, and links to current topic notes. Fresh standalone agents and coordinating agents must read this entry point and the notes related to their task before project work. They must search the wiki before asking the user to explain previous decisions or project terms. Continuing agents will repeat this reading only after a topic change or loss of the necessary context. The entry point will target 500 words or fewer, excluding the numbering reference. That reference will follow the summary; agents will read it only when they must allocate a note number.

**Documentation and subagents.** Before completion, the coordinating or standalone agent must update notes affected by changed behavior, configuration, decisions, user corrections, or known failures. It must correct current guidance, mark replaced decisions as superseded, and add one short session-log link. When no recorded knowledge changes, it may report that result without creating a note. The coordinating agent will give workers the task constraints, selected wiki context, and source paths. Workers will read further notes only when necessary and return documentation changes with their findings. The coordinating agent will own note numbering and final wiki edits unless it assigns a specific note to one worker.

**Search corrections.** In `indexer.py` and `server.py`, `query_wiki` will omit zero-score hits and enforce `top_k` between 1 and 25. Results will identify source paths, indexed roots, timestamps, generations, chunk IDs, and excerpt truncation; responses will report omitted-hit counts within 8,000 characters. A new `read_wiki_passage(project, generation, chunk_id, offset=0)` tool will paginate indexed text by character offset, returning `next_offset` and `complete` within an 8,000-character response. It will reject unknown references and arbitrary file paths. Stale generation responses will tell agents to query again; agents must fetch incomplete evidence before use. MCP will search registered project indexes; agents must read their active checkout for checkout-specific facts.

**Upgrade and acceptance.** `setup-projects.py` will gain an explicit, preview-first upgrade mode for recognized Grimoire sections; ambiguous files will be skipped. Applied upgrades will save original bytes for rollback, and scheduled refreshes will not run contract upgrades. End-to-end tests, written before implementation, will cover no-match queries, complete passage recovery, response limits, and repeated upgrades that keep custom instructions. Fresh-agent trials will compare both contracts in two available harnesses, using Luna with personal memory disabled. Acceptance needs correct decision recovery after subagent handoff, mandatory documentation updates, and less repeated context than the old contract. Repeatable evidence will include setup, prompts, steps, results, token use, elapsed time, and any missing harness coverage.
